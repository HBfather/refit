# RE:FIT

**지난 운동을 기억하고, 오늘의 변화를 기록하는 개인 운동 앱.**

[앱 실행하기](https://hbfather.github.io/refit/) · [디자인·사용성 제안하기](https://github.com/HBfather/refit/issues) · [수정안 살펴보기](https://github.com/HBfather/refit/pulls)

## 왜 만들었나요?

운동하면서 기존 앱의 복잡한 화면과 번거로운 기록 방식이 아쉬웠습니다. 원하는 기능을 직접 정하고 AI의 도움을 받아 RE:FIT을 만들었습니다.

선택한 운동 목적과 프로그램을 기억하고, 지난 중량·반복을 불러와 다음 운동을 바로 시작할 수 있는 앱을 지향합니다. 많은 기능보다 **운동 중 빠르게 읽고, 누르고, 기록할 수 있는 경험**을 중요하게 생각합니다.

## 주요 기능

- **운동 목적 유지:** 최대근력·근비대·근지구력·파워 중 선택
- **종목별 1RM:** 중량·반복·RIR을 이용한 추정값 계산 및 저장
- **운동 프로그램:** 부위별 종목, 중량, 반복, 세트, 휴식 설정
- **운동 기록:** 세트별 실제 수행 기록, 완료 체크, 휴식 타이머
- **다음 운동 이어가기:** 진행 중 운동 재개와 이전 실적을 활용한 새 운동
- **성장 분석:** 종목 중심의 일·주·월·년 변화, 중량·반복·세트·운동량·1RM 그래프
- **모바일 PWA:** 홈 화면 설치와 최초 온라인 준비 후 오프라인 사용
- **JSON 전체 백업·복원:** 기록 이전과 복원 전 확인

기능 설명은 최근 개발 버전 기준입니다. 배포된 앱과 저장소의 버전에 따라 차이가 있을 수 있습니다. 1RM 추정치는 실제 측정값과 구분해서 사용합니다.

## 갤럭시에서 사용하기

1. Chrome에서 [RE:FIT](https://hbfather.github.io/refit/)을 엽니다.
2. 운동 목적을 선택하고 1RM과 프로그램을 설정합니다.
3. 앱의 설치 버튼 또는 Chrome 메뉴의 **홈 화면에 추가 → 설치**를 선택합니다.
4. 오프라인 준비가 완료되면 홈 화면 아이콘으로 실행합니다.

## 기록은 어디에 저장되나요?

현재는 계정이나 서버 데이터베이스 없이 **사용하는 기기의 브라우저 저장소**에 보관합니다. 같은 앱을 사용하는 사람끼리 기록이 공유되지 않으며, 기기 간 자동 동기화도 제공하지 않습니다.

기기 변경이나 브라우저 데이터 삭제에 대비해 JSON 백업을 별도로 보관해 주세요. **개인 운동 기록이 담긴 JSON 파일은 이 공개 저장소나 이슈에 올리지 마세요.** 문제 제보에는 가상 데이터나 개인정보를 가린 화면을 사용해 주세요.

## 디자인·사용성 개선에 도움을 구합니다

특히 아래 부분의 의견과 수정 제안을 기다립니다.

1. **정보의 우선순위:** 운동 중 중량·반복·완료 상태를 빠르게 읽을 수 있는가?
2. **시각적 균형:** 글씨·버튼·아이콘의 비율과 여백이 자연스러운가?
3. **휴대폰 조작:** 작은 화면, 한 손 조작, 숫자 키보드 사용이 편리한가?
4. **분석 화면:** 같은 조건에서 실제로 무엇이 좋아졌는지 쉽게 알 수 있는가?
5. **접근성:** 충분한 명암 대비, 글씨 확대, 색상 외의 상태 표시를 제공하는가?

전체 리디자인뿐 아니라 버튼 하나, 기록 입력 흐름 하나에 대한 제안도 환영합니다. 개발을 하지 않아도 스크린샷에 의견을 표시하거나 디자인 시안을 공유할 수 있습니다.

## 제안·기여 방법

- **피드백:** [Issues](https://github.com/HBfather/refit/issues)에 사용 기기, 불편한 화면, 개선 이유를 적어 주세요.
- **디자인 시안:** 가상 데이터로 만든 수정 전후 이미지나 열람 가능한 디자인 링크를 첨부해 주세요.
- **코드 수정:** 먼저 이슈에서 범위를 이야기한 후, 자신의 복사본에서 수정하고 Pull Request를 보내 주세요.
- **작은 변경부터:** 화면 하나 또는 문제 하나 단위로 보내주시면 검토하기 쉽습니다.

수정안에는 **어떤 문제를 해결했는지, 바뀐 화면, 확인한 기기·화면 크기, 남은 제한**을 함께 적어 주세요. 반영 여부는 앱 관리자가 검토해 결정합니다.

### 유지하고 싶은 기준

- 기존 운동 기록, JSON 백업 호환성, 프로그램과 진행 중 운동을 보존합니다.
- 저장 형식 변경이 필요하면 이전 방법을 먼저 제안합니다. 기록 초기화를 전제로 하지 않습니다.
- PWA 설치·오프라인 기능을 유지합니다. 추가 글꼴·이미지·라이브러리를 사용하면 이용 조건과 오프라인 동작을 함께 확인합니다.
- 외부 분석 도구, 광고, 로그인, 서버 전송 기능은 별도 논의 후 추가합니다.
- 화면을 크게 바꾸기 전에 미리보기로 함께 확인합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면, 운동 기록, 분석 로직 |
| `manifest.webmanifest` | 앱 이름·아이콘·설치 설정 |
| `sw.js` | 오프라인 캐시와 업데이트 |
| `icons/` | 앱 아이콘 |

별도 빌드 과정 없이 정적 HTTPS 호스팅에서 실행하는 구조입니다. 로컬 파일을 직접 여는 방식에서는 PWA 설치·서비스 워커 기능을 확인할 수 없습니다. 화면 수정 시 기본 글씨/큰 글씨, 빈 기록/예시 기록, 모바일에서의 입력과 화면 넘침을 확인해 주세요.
